על השירות

images2pdf (כלי PDF ללוקיישנים) הוא כלי פרטי שמאפשר למשתמש אחד, שאושר מראש, לבחור תמונות מתיקיות בגוגל דרייב שלו וליצור מהן קובץ PDF לשליחה. השירות לא פתוח להרשמה, והגישה אליו מוגנת בסיסמה.

איזו גישה לגוגל דרייב הכלי מבקש, ולמה

  • צפייה בקבצים בדרייב (drive.readonly): כדי לחפש תיקיות של לוקיישנים, להציג את התמונות שבהן, ולהוריד את התמונות שנבחרו כדי ליצור מהן את הקובץ. הכלי לא משנה ולא מוחק קבצים קיימים.
  • קבצים שהכלי יצר (drive.file): כדי ליצור את התיקייה "קבצי PDF" ולשמור בה את הקבצים שהמשתמש יצר. ההרשאה הזו מאפשרת לכלי לכתוב רק לקבצים שהוא עצמו יצר.

המידע מגוגל משמש רק להצגת התיקיות והתמונות ליצירת הקבצים שהמשתמש ביקש. הוא לא נמכר, לא משמש לפרסום, לא משמש לאימון מודלים, ולא מועבר לאף גורם.

מה נשמר בשרת, ולכמה זמן

  • אסימון הגישה לגוגל (refresh token), מוצפן, וכתובת המייל של החשבון שחובר, כדי לוודא שחובר החשבון הנכון. נשמרים עד שמנתקים את החשבון או מבטלים את הגישה.
  • קבצי ה-PDF שנוצרו ופרטי היצירה (הכותרת, מזהה תיקיית הלוקיישן, ושמות של תמונות שלא נכנסו לקובץ): עד 24 שעות, ואז נמחקים.
  • עותקים זמניים של התמונות בזמן היצירה: נמחקים בסוף היצירה.
  • מזהה התיקייה "קבצי PDF" בדרייב.
  • סיסמת הכניסה, כ-hash ולא כטקסט, וזמני ניסיונות כניסה (לרבע שעה, להגבלת ניסיונות).
  • יומני שרת טכניים, בלי שמות קבצים ובלי כתובות מייל.

בדפדפן נשמרת עוגיית כניסה, והבחירה הנוכחית נשמרת בלשונית בלבד. אין בכלי פרסומות ואין כלי מעקב או סטטיסטיקה.

עם מי המידע משותף

עם אף גורם, חוץ משניים שהשירות לא יכול לפעול בלעדיהם: Google (גוגל דרייב והחיבור לחשבון), ו-Render, שרת האחסון שמריץ את הכלי. כל אחד מהם כפוף למדיניות הפרטיות שלו.

איך מבטלים את הגישה

  • בתוך הכלי: בעמוד "חיבור לגוגל" לוחצים "ניתוק החשבון". הכלי מבטל את הגישה אצל גוגל ומוחק את האסימון מהשרת.
  • בחשבון הגוגל: נכנסים ל-myaccount.google.com/linkedapps, בוחרים את הכלי, ולוחצים על הסרת הגישה.

Privacy Policy — images2pdf

Last updated: {{ updated_en }}

About the service

images2pdf (the Location PDF Tool) is a private tool that lets a single pre-authorized user choose photos from folders in their own Google Drive and create a PDF file from them to send. The service is not open to registration, and access is protected by a password.

What Google Drive access the tool requests, and why

  • View files in Drive (drive.readonly): to search for location folders, show the photos in them, and download the selected photos to build the file. The tool does not change or delete existing files.
  • Files the tool created (drive.file): to create the "קבצי PDF" (PDF files) folder and save the PDFs the user created. This permission only lets the tool write to files it created itself.

Data from Google is used only to show folders and photos and to create the files the user asked for. It is not sold, not used for advertising, not used to train models, and not transferred to anyone.

What is stored on the server, and for how long

  • The Google access token (refresh token), encrypted, and the email address of the connected account, to check that the right account was connected. Kept until the account is disconnected or access is revoked.
  • The PDF files created and their job details (title, the location folder ID, and names of photos that could not be included): up to 24 hours, then deleted.
  • Temporary copies of the photos while a file is being created: deleted when it is done.
  • The ID of the "קבצי PDF" folder in Drive.
  • The login password, as a hash and not as text, and the times of login attempts (for 15 minutes, to limit attempts).
  • Technical server logs, without file names and without email addresses.

The browser keeps a login cookie, and the current selection is kept in the browser tab only. The tool has no ads and no tracking or analytics.

Who the data is shared with

No one, except the two services the tool cannot run without: Google (Google Drive and account sign-in), and Render, the hosting server that runs the tool. Each is governed by its own privacy policy.

How to revoke access

  • In the tool: on the "Google connection" page, choose "Disconnect account". The tool revokes access at Google and deletes the token from the server.
  • In your Google Account: go to myaccount.google.com/linkedapps, choose the tool, and remove its access.
